# 5-Minute Demo Video Speaking Script & Presentation Guide

**Project**: AI-Powered Crop Advisory System for Uttarakhand Farmers  
**Target Duration**: 5 Minutes (05:00)

---

## ⏱️ Timeline & Agenda

| Time Code | Section | Video Action / Display Screen | Detailed Speaking Script |
|---|---|---|---|
| **00:00 – 00:30** | 1. Introduction | Landing Page (`/`) with Dark/Light Theme toggle | *"Hello everyone! Welcome to the presentation of the AI-Powered Crop Advisory System, a web application built to address the unique agricultural challenges faced by farmers in Uttarakhand's hill regions. Mountain farming involves step terraces, altitude variations, and native crops like Mandua finger millet and Munsiyari Rajma. Our platform provides 24/7 localized advisory support, disease management, and crop registry tools."* |
| **00:30 – 02:30** | 2. Project Walkthrough | Full application user flow execution | *"Let's begin our live application walkthrough:<br/>• **Signup & Login**: First, we navigate to Signup (`/signup`) where farmers register with their district and state metadata, or switch to Login (`/login`) with credential or single-click Google OAuth authentication.<br/>• **Dashboard**: Upon logging in, the Dashboard (`/dashboard`) greets the user with personal farmer credentials and an aggregated overview of farming activities.<br/>• **Crops Registry**: On the Crops page (`/crops`), we can manage the regional crop database—searching by crop name (e.g. Mandua), creating new crop profiles, updating soil and fertilizer attributes, or deleting obsolete records.<br/>• **AI Chatbot & History**: Next, in the AI Chatbot interface (`/chatbot`), we submit a query like 'How to manage Apple Scab disease in Uttarkashi?'. The assistant responds using Google Gemini AI formatted in rich Markdown. We can copy responses, pin important chats to the top using drag-and-drop, star favorites, rename session titles, or export/import conversation sessions as JSON.<br/>• **Analytics**: Finally, the Dashboard section updates live with 8 statistic cards and 3 Chart.js graphs tracking conversation growth and chat interactions."* |
| **02:30 – 03:30** | 3. Show Deployment | Production browser tabs | *"Now, let's examine the production deployment environment:<br/>• **Frontend Deployment**: Hosted on Vercel at `https://crop-advisory-tau.vercel.app`, integrated with global edge CDN distribution and instant SSL certificate encryption.<br/>• **Backend API Deployment**: Hosted live on Render Web Services at `https://crop-advisory-p0ng.onrender.com`.<br/>• **Health Endpoint Check**: Visiting `/api/health` returns `{"status":"healthy","database":"connected"}`, proving real-time connection pooling with Supabase PostgreSQL."* |
| **03:30 – 04:30** | 4. Code Walkthrough | VS Code editor structure | *"Now let's review the technical code structure:<br/>• **Frontend Architecture**: Built with Next.js 16 App Router, React 19, and Tailwind CSS. Notice client service modules in `src/lib/api.js` and `auth.js` that attach JWT headers dynamically without hardcoding URLs.<br/>• **Backend & API Layer**: Express.js REST API in `backend/server.js` with structured controllers, route validators, rate limiting, and centralized error handling middleware.<br/>• **Database Layer**: Supabase PostgreSQL managed via custom ORM models (`userModel`, `cropModel`, `chatHistoryModel`) utilizing JSONB for flexible chat history storage."* |
| **04:30 – 05:00** | 5. Conclusion | Landing Page or Slides | *"In summary, this capstone project demonstrates a full-stack, secure, AI-integrated application ready for real-world agricultural impact. Key learnings include decoupling Next.js App Router with Express APIs and optimizing AI response streaming.<br/>For future work, we aim to add voice recognition, offline PWA support, and computer vision leaf disease diagnosis.<br/>Thank you for watching!"* |
