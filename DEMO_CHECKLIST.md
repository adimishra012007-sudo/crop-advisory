# Demo Recording Preparation Checklist

Use this checklist before pressing record to ensure a smooth, professional 5-minute video demonstration.

---

## 📋 Pre-Recording Setup Checklist

- [ ] **Browser Tabs Ready**:
  - [ ] Frontend Production: `https://crop-advisory-tau.vercel.app`
  - [ ] Backend Health API: `https://crop-advisory-p0ng.onrender.com/api/health`
  - [ ] Vercel Dashboard / Deployment: `https://vercel.com`
  - [ ] Render Dashboard: `https://dashboard.render.com`
  - [ ] GitHub Repository: `https://github.com/adimishra012007-sudo/crop-advisory`
- [ ] **Zoom Level**: Browser zoom set to 100% or 110% for crisp readability.
- [ ] **Dark Mode / Theme Toggle**: Verify ThemeToggle functions smoothly between Light and Dark themes.
- [ ] **Stable Internet Connection**: Ensure active internet connection for live Gemini AI queries and Supabase database requests.
- [ ] **Login Credentials Ready**: Test account credentials prepared (e.g. farmer user account).
- [ ] **AI Chatbot Demo Query**: Query string pre-copied (*"How to manage Apple Scab disease in Uttarkashi?"*).
- [ ] **Dashboard Demo**: Confirm analytics cards and Chart.js graphs load without errors.
- [ ] **Crop Page**: Verify crop records list and search filter function cleanly.
- [ ] **Health Endpoint**: Verify `/api/health` returns `{"status":"healthy","database":"connected"}`.
- [ ] **GitHub Repository & README**: Verify `README.md` and repository structure are open in VS Code.
- [ ] **Deployment URLs**: Confirm all production URLs match deployed links.
- [ ] **End Recording**: Verify screen recording controls and audio microphone levels.
